# gte-small

Model files in this folder (`model_quantized.onnx`, `vocab.txt`, `config.json`, `tokenizer_config.json`)
are unmodified copies of the ONNX export [Xenova/gte-small](https://huggingface.co/Xenova/gte-small)
of [thenlper/gte-small](https://huggingface.co/thenlper/gte-small) (General Text Embeddings, Alibaba DAMO),
licensed under the MIT License.

NULL serves them from its own domain so Private Memory in NULL Chat can pick the notes that fit a
message entirely in the visitor's browser, without contacting Hugging Face.
